# Product

## Platform

web

## Product Purpose

kaykay is a Svelte 5 flow editor library with typed port connections. Its demo site shows developers how to build interactive node-based applications.

## Capabilities and Constraints

- Preserve the existing demo site's visual language.
- The Live System example demonstrates animated traffic, computed metrics, load controls, pause/reset, and service failure/recovery.
- Keep domain-specific simulation in the example, separate from the general-purpose library.
- The first example is a small testable simulation, not a full Breakscale replacement.

## Brand Commitments

- The documentation site's primary accent is #FFDC58 in both light and dark themes, with #242321 text on filled buttons.
- Light-theme accent text and focus indicators use dark gold (#806000) for contrast; dark-theme accents use the primary yellow.
- Preserve semantic error/success colors, typed-port palettes, and the Blender example's separate visual identity.
